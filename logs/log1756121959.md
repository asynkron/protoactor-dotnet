# Refactor Cluster initialization and diagnostics

## Summary
- Extracted diagnostic gathering into `ClusterDiagnostics` service.
- Moved extension and serialization registration to `ClusterInitialization` helpers.
- Introduced `ClusterMetricsCollector` to encapsulate metrics observers and keep `Cluster` facade thin.
- Updated `Cluster` to delegate diagnostics, initialization and metrics to the new services without altering public API.
- Verified via core test suites to ensure behaviour remains intact.

## Motivation
Separating diagnostics, registration and metrics logic simplifies the `Cluster` facade, improving maintainability and isolating concerns. This modular design makes each responsibility easier to test and extend.
