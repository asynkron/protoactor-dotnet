## Typed logging and runner refactor

- Replaced delegate-based logging in `ConnectionRunner` with typed logger messages for consistent structured logging.
- Extracted reader and writer loops into dedicated async methods to clarify `RunAsync` flow.
- Updated `ServerConnector` to provide an `ILogger` to `ConnectionRunner`.
- Added generated log message definitions in `ConnectionRunnerLogMessages`.

These changes improve readability and ensure logging leverages source-generated message templates for performance.
